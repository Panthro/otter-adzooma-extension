Install Otter Adzooma Chrome Extension

This extension enhances the Adzooma dashboard with advanced reporting and charts. It is distributed privately and will auto-update from this site.

Note: This extension is not in the Chrome Web Store. You must follow these steps for installation and auto-updates.

Step 1: Download the Extension

Download extension.zip

Save this file to your computer and extract it.

Step 2: Install the Extension in Chrome

  1. Open chrome://extensions in Chrome. Copied! (Copy and paste this into your address bar.)
  2. Enable Developer mode (top right).
  3. Drag and drop the downloaded extension.zip file onto the Chrome extensions page.

How to Manually Update the Extension

When a new version is published, you will need to download and install the latest extension.zip from this page.
Note: Automatic updates are not available for unpacked extensions. To update, simply repeat the installation steps above with the new file.

Troubleshooting

  • If you see an error when loading the extension, make sure you are dragging and dropping the extension.zip file directly into Chrome.
  • Ensure Developer mode is enabled in the top right of the chrome://extensions page.
  • If the extension does not appear after installation, try refreshing the chrome://extensions page or restarting Chrome.
  • If you continue to have issues, contact your team lead for support.
