Install Otter Adzooma Chrome Extension

This extension enhances the Adzooma dashboard with advanced reporting and charts. It is distributed privately and will auto-update from this site.

Note: This extension is not in the Chrome Web Store. You must follow these steps for installation and auto-updates.

Step 1: Download the Extension

Download otter-adzooma.crx

Save this file to your computer.

Step 2: Download the Update JSON File

Download otter-adzooma-update.json

This file tells Chrome where to check for updates. After your first install, update the filename to match your extension ID (see below).

The file content should look like:

{
  "external_update_url": "https://panthro.github.io/otter-adzooma-extension/update.xml"
}

Step 3: Place the JSON File

Move the JSON file to the Chrome External Extensions directory:

  • Windows: C:\Users\<your-user>\AppData\Local\Google\Chrome\User Data\External Extensions\
  • macOS/Linux: ~/Library/Application Support/Google/Chrome/External Extensions/

Rename the file to <your-extension-id>.json (replace <your-extension-id> with the actual ID from chrome://extensions/ after first install).

Step 4: Install the Extension

  1. Open chrome://extensions/ in Chrome.
  2. Enable Developer mode (top right).
  3. Drag and drop otter-adzooma.crx onto the page to install.
  4. After install, find your extension's ID and rename the JSON file as described above.
  5. Restart Chrome (chrome://restart in the address bar).

How Auto-Update Works

Chrome will periodically check https://panthro.github.io/otter-adzooma-extension/update.xml for updates. When a new version is published, your extension will update automatically.

Troubleshooting

  • If the extension does not appear, double-check the JSON file location and name.
  • Make sure you restart Chrome after placing the JSON file.
  • Contact your team lead if you have issues.
